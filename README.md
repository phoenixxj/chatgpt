# 文件交付

以下文件均可单独下载，密码在原对话中提供，不存放于本仓库。

| 文件 | 内容 |
|---|---|
| [完整资料包 ZIP](delivery/F22-complete.zip) | 全部原始说明、图纸、参数及计算脚本 |
| [说明正文 PDF](delivery/F22-notes.pdf) | 完整的结构冻结说明，可直接阅读 |
| [七张图纸 PDF](delivery/drawings.pdf) | 七张配套图纸 |

打开文件页面后，点击 **Download raw file** 下载。

## 打开完整 ZIP

使用支持 AES 加密 ZIP 的工具（例如 7-Zip、WinRAR）输入原对话中的密码，得到 `F22-original.zip`；再解压这个普通 ZIP，即可取得全部原始文件，包括 Markdown 正文。

PDF 使用同一个密码打开。

## 无需解压软件的原入口

[package.html](delivery/package.html) 保留可用。下载后用 Chrome 或 Edge 本地打开，输入同一密码，点击“解密并下载 ZIP”，也能获得原始普通 ZIP。

仓库仅存放受保护的交付文件，不包含明文资料或密码。文件属于结构工作基准，公差与刚度、整柜适配、创造性判断仍需分别完成。
