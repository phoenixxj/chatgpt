# 文件交付

本仓库为文件下载提供入口。交付文件使用密码保护，密码只在原对话提供，不存放于本仓库。

## 下载完整资料

1. 在仓库首页点击绿色 **Code → Download ZIP**。
2. 解压下载的仓库 ZIP，打开 `delivery/package.html`。
3. 用 Chrome 或 Edge 打开该文件，粘贴原对话中的密码，点击“解密并下载 ZIP”。
4. 得到的 `F22-complete.zip` 是普通 ZIP，包含完整说明、图纸、参数与计算脚本。

也可以进入 `delivery/package.html` 的文件页面，选择 **Download raw file**，保存 HTML 后在本地打开。

## 单独查看图纸

下载 [图纸 PDF](delivery/drawings.pdf)，用支持密码 PDF 的阅读器打开，输入同一密码。

## 文件范围

文件为结构工作基准及图文核对资料。后续公差与刚度、整柜适配、创造性判断仍需分别完成。

## 保护方式

- HTML 使用浏览器本地解密，密码和资料不发送到服务器。
- PDF 使用密码加密。
- 仓库不存放密码，不存放未加密的原始资料包。
